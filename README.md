# Community submission form

[Open the public submission page](https://danielreallydoesexist.github.io/ReloadedU-eshop-submission/).

This MIT-licensed page collects suggestions for free, redistributable Wii U homebrew. It sends them to a private review queue in the Reloaded U Supabase project. It does not upload packages, publish games, or verify a PNID. Never enter a password.

GitHub Pages serves `index.html`, `style.css`, and `submit.js` from the root of the `main` branch. Validation, rate limiting, and private records live in Supabase. No secret key or game package is stored in this repository.

An operator must verify the game source, license, distribution rights, and package safety before publication. Developer display names are unverified.
